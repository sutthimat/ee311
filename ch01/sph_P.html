Spherical Coordinates at P

In spherical coordinates, point P is given by r, θ, φ. Change the values and watch the position of the point and the unit vectors ar, aθ, aφ, whose directions change with the point.

x = r sinθ cosφ
y = r sinθ sinφ
z = r cosθ
r = √(x² + y² + z²)    θ = cos⁻¹(z/r)    φ = tan⁻¹(y/x)    ranges: 0 ≤ r, 0 ≤ θ ≤ 180°, 0 ≤ φ < 360°
