Vector Addition and Subtraction

Two vectors add by the parallelogram law: drawn from one tail, they span a parallelogram whose diagonal from that tail is A + B. Drawn head to tail, B starts at the tip of A and the sum runs from the tail of A to the tip of B; either order gives the same vector, A + B = B + A. Subtraction adds the reversed vector, A − B = A + (−B), and a scalar k multiplies the length by |k|, reversing the direction when k < 0. In components, add the corresponding components (Hayt §1.2). Equations used

A + B = (Ax + Bx) ax + (Ay + By) ay + (Az + Bz) az
A − B = A + (−B)
kA = kAx ax + kAy ay + kAz az,   |kA| = |k| |A|
|A| = √(Ax² + Ay² + Az²)
A + B = B + A   A + (B + C) = (A + B) + C   (r + s)(A + B) = rA + rB + sA + sB

A vector drawn as an arrow may be moved parallel to itself without changing it; that is what head-to-tail addition does. Dividing by a scalar is multiplying by its reciprocal, and A = B when A − B = 0. In a vector field, only vectors at the same point are added: near a horseshoe magnet, the total magnetic field at a point is the earth's field there plus the magnet's field there.
