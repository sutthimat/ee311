Work in a static E field is path-independent

Notice: the running totals differ along the way, but every path from A to B ends at the same W = Q(VB − VA); around a closed loop W = 0.

Field:
W=-Q\int_A^B\mathbf E\cdot d\mathbf L=Q\,(V_B-V_A) \oint\mathbf E\cdot d\mathbf L=0 W = work done by an external agent. Integral computed numerically along each drawn path (adaptive Gauss–Legendre). Drag A, B, or the curve handle ●.
